# TradeBuddy 1.22.0 (2026-11-21)

This branch only holds the newest TradeBuddy app file, for updates from inside the app.

## What's new

- New (optional): the auto-trader can run on your own TradeBuddy server - it keeps trading its pretend money every market minute with this app closed or the phone off. Auto-trader → "Let it trade with the app closed" → compare and move it once.
- The phone then shows exactly what the server's auto-trader does (its trades, money, learning and log) and your switch, amount and protection changes go to the server. The phone never runs a second copy.
- Your phone's auto-trader is kept as a backup when it moves, and the server keeps backups too. Nothing is ever mixed; "Run it on this phone again" brings it back.
- Safer everywhere: no new auto-trader trades from prices older than 2 minutes.
- Pretend money only - nothing is ever sent to Upstox. Not a guarantee - you place every real order yourself.

## How to update

- **In TradeBuddy:** tap **Update now** on Home (or Me → App updates → Check now). Your practice money, settings and login stay.
- **Without the app:** open [TradeBuddy-1.22.0.apk](TradeBuddy-1.22.0.apk) on the phone → **View raw** to download → open the file → Install.
